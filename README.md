# Simple Todo App

A web application that allows the user to write, monitor and manage tasks by due date. 

## Functionality

Give a more detailed explanation of the project and its functionality.

* The Todo App includes the following features:

* Add new tasks using a popup form

* Optional due dates for tasks

* Automatic date formatting for better readability

* Visual feedback to prevent invalid inputs

* Delete tasks from the list

* Unique IDs generated for each task using UUID


## Technology

* HTML

* CSS

* JavaScript

* Object-Oriented Programming (OOP)

* JavaScript Modules (import/export)

* Classes and encapsulation

* DOM manipulation

* Event listeners

* Form validation
